# Guarant — гарант-бот со страховым депозитом

Телеграм-бот для безопасных сделок: деньги покупателя удерживаются сервисом
и уходят продавцу только после подтверждения. Плюс страховой депозит,
который любой может проверить по юзернейму.

Пополнение — только крипта: **CryptoBot**, **USDT TRC20**, **USDT BEP20**.
Проценты, лимиты, адреса кошельков и тексты меняются прямо в админке бота
и применяются сразу, без перезапуска.

---

## Что уже работает

**Сделки**
- Продавец или покупатель создаёт сделку, получает ссылку-приглашение
  (`t.me/бот?start=deal_КОД`), вторая сторона заходит по ней.
- Покупатель оплачивает с баланса — средства уходят под удержание.
- Покупатель подтверждает получение — продавец получает сумму за вычетом комиссии.
- Спор: любая сторона открывает его, администрация отдаёт деньги продавцу
  или возвращает покупателю.
- Комиссию платит продавец, покупатель или пополам — выбирается при создании.
- Неоплаченные сделки отменяются автоматически (срок настраивается).

**Страховой депозит**
- Пополняется криптой напрямую или переводом с баланса.
- Снимается на баланс либо выводится в крипту.
- Настраивается: минимум, максимум, заморозка на N дней, комиссия за снятие,
  обязательный депозит для создания сделок.

**Проверка по юзернейму** — то, ради чего депозит и нужен
- Кнопка «🔍 Проверить», команда `/check`, или просто отправленный боту `@username`.
- Ищет по ID, юзернейму, `@юзернейму` и ссылке `t.me/...`; регистр не важен.
- Показывает депозит, число закрытых сделок, оборот, дату регистрации,
  статус доверия и метку блокировки.
- Каждое поле можно скрыть в админке; порог статуса «Надёжный» тоже настраивается.

**Пополнение**
- CryptoBot — счёт через Crypto Pay, оплата подхватывается автоматически.
- TRC20 / BEP20 — общий кошелёк, платёж опознаётся по уникальной сумме
  (к сумме добавляются случайные микро-центы: `10.00` → `10.004217`).
- Зачисляется фактически пришедшая сумма, так что переплата не теряется.
- Если человек отправил не ту сумму — админ зачисляет счёт вручную из админки.

**Вывод**
- В CryptoBot: можно включить автовыплату (прямой перевод, при неудаче — именной чек).
- Напрямую на TRC20 / BEP20: заявка уходит админу, он платит и отмечает выполненной.
- Комиссия задаётся отдельно для каждого способа: процент + фиксированная часть за сеть.
- Деньги списываются при создании заявки и возвращаются, если её отклонили.

**Админка** (`/admin`) — 77 параметров в 10 разделах
- Основное, Сделки и комиссия, Страховой депозит, Пополнение, Вывод,
  Реквизиты и API, Проверка по юзернейму, Кнопки меню, Иконки разделов, Тексты.
- Очереди: заявки на вывод, споры, неоплаченные счета.
- Пользователи: поиск по `@username` или ID, правка баланса и депозита,
  бан, верификация, назначение админов, история операций.
- Статистика, рассылка, кнопка «Проверить API» — проверяет токен CryptoBot
  и читаются ли кошельки.

## Интерфейс

Навигация двухуровневая, как на макете:

- **Нижняя клавиатура** — разделы верхнего уровня. Раскладка: широкая кнопка
  «Начать сделку», затем две пары (Депозит / Проверить, Профиль / Информация),
  затем широкая «Наши проекты», и «Админка» — только администраторам.
  Ставится один раз на `/start` и висит всегда (`is_persistent`).
- **Инлайн-кнопки** — действия внутри экрана: оплатить, подтвердить, отмена.

Одно сообщение не может нести обе клавиатуры сразу, поэтому нижняя ставится
один раз, а каждый экран приходит со своими инлайн-кнопками. Нажатие нижней
кнопки уводит из любого диалога — её роутер подключён первым.

**Подписи кнопок меняются в админке** (`Настройки → ⌨️ Кнопки меню`), без
деплоя. Пустая подпись = кнопка скрыта.

**Вёрстка сообщений** — `bot/utils/style.py`: иконка и жирный заголовок,
параметры деревом, значения моноширинные.

```
🔍 Проверка пользователя
├ Имя: Greedy
├ Юзернейм: @GreedyHatesAI
├ ID: 8561401973
╰ В сервисе с: 18.09.2026
```

**Профиль** свёрстан списками — заголовок раздела с иконкой, под ним строки
`• Подпись: значение`:

```
❓ Информация
• Никнейм: @user
• ID: 7727821854
• Кол-во сделок: 4

📊 Статистика сделок
• Сделки (4): $ 213,50
• Покупатель (0): $ 0,00
• Продавец (4): $ 213,50
```

**Валюта** настраивается в разделе «Основное»: символ (`$`, `USDT`, любой),
сторона (`$ 10,00` или `10.00 USDT`) и разделитель дробной части.

**Про премиум-эмодзи.** Подпись кнопки Telegram передаёт обычной строкой,
без entities, — поэтому премиум-эмодзи ставятся в **текст сообщения**, а не
на кнопку. Иконки заголовков вынесены в раздел «✨ Иконки разделов»: пришлите
туда премиум-эмодзи прямо с клавиатуры Telegram, бот сохранит его тегом
`<tg-emoji>` и будет отдавать как есть.

Отправлять такие теги может только бот, у которого **куплен юзернейм на
Fragment**. Если права нет, Telegram отклоняет сообщение целиком — поэтому
бот ловит такой отказ и переотправляет текст с обычным эмодзи вместо
премиум. Экран не сломается, просто иконка будет обычной.

## Установка

Нужен Python 3.11+.

```bash
git clone https://github.com/glurp1k/Guarant-.git
cd Guarant-

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
```

В `.env` задаются только три вещи:

| Параметр       | Что это                                                       |
|----------------|---------------------------------------------------------------|
| `BOT_TOKEN`    | токен от [@BotFather](https://t.me/BotFather)                 |
| `ADMIN_IDS`    | ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)), через запятую для нескольких |
| `DATABASE_URL` | по умолчанию SQLite, для продакшена можно PostgreSQL          |

Запуск:

```bash
python run.py
```

База и все настройки создадутся сами при первом старте.

## Первая настройка

Откройте бота → `/admin` → **🛠 Настройки** → **🔑 Реквизиты и API** и впишите:

- `cryptobot_token` — @CryptoBot → **Crypto Pay** → **Create App** → токен;
- `usdt_trc20_address` — ваш адрес приёма USDT в сети TRON;
- `usdt_bep20_address` — адрес приёма USDT в BNB Chain;
- `bscscan_api_key` — **обязателен** для BEP20, бесплатный ключ на
  [etherscan.io/apis](https://etherscan.io/apis) (один ключ работает и для BSC);
- `trongrid_api_key` — необязателен, но без него упираешься в публичные лимиты
  ([trongrid.io](https://www.trongrid.io)).

Те же значения можно записать одной командой, не вводя их в чат:

```bash
python scripts/configure.py \
  --cryptobot-token 123456:AA... \
  --trc20 TF9Vf... \
  --bep20 0xc92f... \
  --bscscan-key ABCDEF

python scripts/configure.py --show     # посмотреть, что сейчас стоит
```

Проверить, что всё подключилось: `/admin` → **🔌 Проверить API**.

> ⚠️ Токен Crypto Pay — это доступ к деньгам. Если он где-то засветился
> (в переписке, скриншоте, коммите) — отзовите его в @CryptoBot
> и создайте новый.

## Как настраивается экономика

Всё в `/admin → Настройки`, применяется сразу:

| Хочу                                  | Раздел → параметр                            |
|---------------------------------------|----------------------------------------------|
| комиссия гаранта 5%                   | Сделки → `deal_commission_percent`           |
| минимальная комиссия 1 USDT           | Сделки → `deal_commission_min`               |
| минимальный депозит 25 USDT           | Депозит → `deposit_min`                      |
| депозит нельзя снять 7 дней           | Депозит → `deposit_lock_days`                |
| без депозита сделки не создавать      | Депозит → `deposit_required_for_deal`        |
| комиссия вывода TRC20 2% + 1 USDT     | Вывод → `withdraw_fee_trc20_percent` / `_fixed` |
| автовыплата через CryptoBot           | Вывод → `withdraw_auto_cryptobot`            |
| скрыть размер депозита при проверке   | Проверка → `check_show_deposit`              |
| статус «Надёжный» от 500 USDT         | Проверка → `check_trusted_from`              |
| свой текст приветствия и правил       | Тексты → `text_start`, `text_rules`          |
| премиум-эмодзи в заголовках           | Иконки разделов → `icon_info`, `icon_stats`, … |
| показывать суммы в USDT, а не в `$`   | Основное → `currency_symbol`, `currency_position` |
| переименовать кнопку меню             | Кнопки меню → `btn_deal`, `btn_profile`, …   |
| спрятать кнопку меню                  | Кнопки меню → стереть подпись                |
| закрыть бота на техработы             | Основное → `maintenance`                     |

Тексты поддерживают HTML-разметку Telegram (`<b>`, `<i>`, `<code>`, ссылки)
и подставляют `{name}` — имя пользователя.

```
  db/

    types.py             деньги: Decimal в Python, целые микро-единицы в БД
  services/
    settings.py          реестр всех настраиваемых параметров ← добавлять сюда
    ledger.py            единственное место, где меняются балансы
    deals.py             жизненный цикл сделки
    deposits.py          страховой депозит и карточка проверки
    payments.py          счета на пополнение
    withdrawals.py       заявки на вывод и комиссии
    watcher.py           фоновая проверка платежей
    crypto/              CryptoBot, TronGrid, BscScan
  filters_reply.py       нажатие кнопки нижней клавиатуры
  handlers/
    reply_menu.py        кнопки нижней клавиатуры, подключается первым
    common.py deals.py deposit.py topup.py withdraw.py check.py fallback.py
    admin/               меню, настройки, очереди, пользователи
  keyboards/
    reply.py             нижняя клавиатура ← раскладка и подписи
    user.py admin.py     инлайн-клавиатуры
    callbacks.py         callback-данные
  utils/
    style.py             вёрстка сообщений (дерево, списки, заголовки)
    render.py            один экран для инлайна и нижней клавиатуры,
                         откат премиум-эмодзи на обычное
    money.py             суммы в оформлении из админки
scripts/
  selfcheck.py           прогон денежных сценариев без сети
  configure.py           запись реквизитов в базу
```

### Добавить новый параметр в админку

Одна строка в `bot/services/settings.py`:

```python
SettingDef("referral_percent", "5", "decimal", "Реферальный процент", "general"),
```

В админке он появится сам — отдельный код не нужен.

## Проверка сборки

```bash
python scripts/selfcheck.py
```

Гоняет на временной базе: пополнение (в том числе защиту от двойного
зачисления), сделку с удержанием и комиссией, возврат по спору, депозит,
вывод с возвратом при отказе, запрет ухода баланса в минус, поиск по ID и
ссылке, вёрстку карточки, раскладку нижней клавиатуры, целостность
callback-данных и реестра настроек. Сеть не нужна.

## Что стоит знать про деньги

- **Суммы — только Decimal.** В базе лежат целые микро-единицы (6 знаков),
  так что копейки не теряются на округлениях (`bot/db/types.py`).
- **Балансы меняются только через `services/ledger.py`**, и каждое изменение
  пишется в журнал `transactions` — любую сумму можно объяснить.
- **Приватные ключи бот не хранит.** Блокчейн только читается; выплаты
  TRC20/BEP20 подтверждает человек. Автоматика есть только у CryptoBot,
  где для этого существует API.
- **Средства сделки не лежат ни на чьём счету**, пока она в статусе
  «у гаранта»: они списаны у покупателя и ещё не начислены продавцу.
